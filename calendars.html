下一参考期 · 透明基准预测

模型方法与局限

点预测 = 最近连续三期的算术平均。用此前三期逐期预测最近36个月、20个季度或104周，计算绝对误差 MAE，并与沿用前值比较。区间 = 点预测 + 历史预测残差的 P10 / P90；它是经验误差范围，不是经过校准的80%置信区间。使用当前修订历史数据，存在版本差异，不能代表当时可实现的预测表现。未使用市场预期、分项因子、实时新闻或因果价格模型。

指数月环比 = (本期 / 上期 − 1) × 100；非农新增 = 本期就业人数 − 上期；GDP 环比折年率 = [(本季 / 上季)^4 − 1] × 100。失业率及数量序列保留原单位。全部为季调数据；这里不把季调 CPI 同比伪装为官方未季调同比。

04产业追踪

宏观主线
NFP → CPI / PPI → PCE → FOMC

这是观察框架，不是固定先后顺序。市场反应取决于实际值相对预期的差异、修正和当时的增长 / 通胀环境；同一数据可能产生不同方向的反应。

半导体主线
TSMC → Earnings → Guidance
